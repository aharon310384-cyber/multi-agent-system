# AgentMemory — Полное руководство

## Что такое AgentMemory

AgentMemory — это система долговременной памяти для AI-агентов. В отличие от простых заметок или баз знаний, AgentMemory не просто хранит информацию — она **структурирует, связывает и превращает сырые данные в знания**.
и Это По сути, превращает память из «блокнота» в «мозг» — с ассоциациями, обобщениями и автоматической организацией.
Самая интересная часть

В changelog всплывает:

lessons now injected into mem::context

Это уже не storage.
Это procedural learning.

То есть агент начинает:

извлекать lessons
переиспользовать patterns
переносить опыт между сессиями

Это шаг в сторону:

adaptive agents
long-horizon workflows
pseudo-persistent cognition

### Аналогия из жизни

Представьте: вы ведёте бизнес и общаетесь с сотнями людей каждый день. Без памяти — каждый разговор начинается с нуля: «Привет, я Павел». С AgentMemory — как с ассистентом, который **помнит всё**: что обсуждали вчера, какой бюджет вы заложили на рекламу, что клиент X попросил скидку, в каком канале у вас лучшая конверсия.

## 4-Tier консолидация памяти

Консолидация — автоматический процесс превращения сырых данных в знания. Работает как опыт хорошего сотрудника: сначала запоминает факты, потом выделяет паттерны, потом формирует экспертизу.

### Tier 1: Working Memory (Рабочая)

**Что:** Сырые наблюдения из текущей сессии. Всё, что произошло сегодня.

**Примеры:**
```
"Обсудили с клиентом запуск рекламы в Instagram — бюджет 50к/мес"
"Клиент Мария попросила скидку 15% на второй заказ"
"Лучшая конверсия — у Telegram-канала (3.2%), хуже всего — Facebook (0.8%)"
```

### Tier 2: Episodic Memory (Эпизодическая)

**Что:** Группировка наблюдений по событиям. «Что произошло и когда».

**Пример:**
```
"Встреча с клиентом Иван 26.05.2026":
  - Обсудили запуск рекламы в Instagram (бюджет 50к/мес)
  - Клиент хочет таргет на аудиторию 25-35 лет
  - Дедлайн — запуск через 2 недели
```

### Tier 3: Semantic Memory (Семантическая)

**Что:** Извлечённые знания и факты. «Что я знаю о бизнесе».

**Примеры:**
```
"Telegram-канал даёт конверсию 3.2% — лучший канал для нашей ниши"
"Клиенты из сегмента B2B предпочитают оплату по счёту, не картой"
"Средний цикл сделки — 14 дней от первого контакта до оплаты"
"Аудитория 25-35 лет лучше всего реагирует на видео-креативы"
```

### Tier 4: Procedural Memory (Процедурная)

**Что:** Навыки, процедуры, паттерны. «Как делать вещи».

**Пример:**
```
"Процедура: онбординг нового клиента"
  1. Уточнить цели и KPI
  2. Определить бюджет и сроки
  3. Выбрать каналы продвижения
  4. Создать контент-план
  5. Настроить аналитику
  6. Запустить пилот на 10% бюджета
  7. Проанализировать результаты через 7 дней
  8. Масштабировать успешные каналы
```

## 53 инструмента — полный обзор

### 📌 8 нативных инструментов (вызываются напрямую)

#### 1. memory_recall — Поиск по памяти

**Для чего:** Найти прошлые решения, наблюдения, контекст по теме.

**Примеры использования:**
```
memory_recall("какой бюджет на рекламу у клиента Иван")
memory_recall("конверсия по каналам маркетинга")
memory_recall("скидки для постоянных клиентов")
memory_recall("результаты последней рекламной кампании")
```

#### 2. memory_save — Сохранение в память

**Для чего:** Явно сохранить важный факт, решение, паттерн.

**Примеры:**
```
memory_save(
  content="Клиент Иван: бюджет на Instagram-рекламу 50к/мес, аудитория 25-35 лет",
  type="fact",
  concepts=["клиент", "иван", "реклама", "instagram", "бюджет"]
)

memory_save(
  content="Telegram-канал — лучший канал по конверсии (3.2%)",
  type="pattern",
  concepts=["telegram", "конверсия", "маркетинг", "каналы"]
)

memory_save(
  content="Клиенты B2B предпочитают оплату по счёту, не картой",
  type="preference",
  concepts=["b2b", "оплата", "предпочтения"]
)
```

#### 3. memory_smart_search — Гибридный поиск

**Для чего:** Продвинутый поиск с авто-тегированием.

**Пример:**
```
memory_smart_search("какие каналы дают лучшую конверсию")
memory_smart_search("бюджеты клиентов на рекламу")
```

#### 4. memory_consolidate — Консолидация памяти

**Для чего:** Запустить пайплайн — превращение наблюдений в знания.

**Пример:**
```
memory_consolidate(tier="episodic")  # группировка по событиям
memory_consolidate(tier="semantic")  # извлечение фактов
memory_consolidate(tier="procedural")  # формирование процедур
```

#### 5. memory_sessions — Список сессий

**Для чего:** Просмотреть прошлые разговоры и их контекст.

#### 6. memory_reflect — Рефлексия

**Для чего:** Анализ скрытых связей, генерация инсайтов.

**Пример:**
```
memory_reflect(maxClusters=5)
# → "Заметил паттерн: клиенты, которые начинают с малого бюджета,
#    через месяц увеличивают его в среднем на 40%"
```

#### 7. memory_lesson_save — Сохранение урока

**Для чего:** Зафиксировать извлечённый урок с оценкой уверенности.

**Примеры:**
```
memory_lesson_save(
  content="Клиенты лучше реагируют на кейсы с цифрами, чем на абстрактные обещания",
  confidence=0.9,
  context="маркетинг, продажи, презентации",
  tags=["продажи", "маркетинг", "кейсы"]
)

memory_lesson_save(
  content="Запуск рекламы в понедельник даёт на 15% больше конверсий, чем в пятницу",
  confidence=0.75,
  context="реклама, тайминг",
  tags=["реклама", "конверсия", "тайминг"]
)

memory_lesson_save(
  content="Клиенты из Чебоксар предпочитают личные встречи, а не созвон",
  confidence=0.85,
  context="регион, формат встреч",
  tags=["регион", "встречи", "предпочтения"]
)
```

#### 8. memory_diagnose — Диагностика

**Для чего:** Проверка здоровья всех подсистем памяти.

#### 📚 Memory Slots — редактируемые блоки памяти

Как страницы в блокноте — структурированные заметки по темам.

**Рекомендуемые слоты:**
- `clients` — информация о клиентах
- `campaigns` — рекламные кампании
- `budgets` — бюджеты и финансы
- `competitors` — конкуренты
- `ideas` — идеи и гипотезы
- `learnings` — извлечённые уроки

**Примеры:**
```
memory_slot_create(name="clients", content="## Клиенты\n")
memory_slot_append(name="clients", content="- Иван: B2B, бюджет 50к/мес, Instagram\n")
memory_slot_append(name="clients", content="- Мария: B2C, бюджет 20к/мес, Telegram\n")
memory_slot_get(name="clients")
```

## 12 автоматических hooks

AgentMemory автоматически извлекает знания из потока работы:

| Hook | Что делает | Пример |
|------|-----------|--------|
| **on_message** | Анализирует каждое сообщение | Упомянут новый клиент → автоматически запомнит |
| **on_file_read** | Извлекает знания при чтении файлов | Прочитал таблицу бюджетов → запомнит цифры |
| **on_file_write** | Фиксирует изменения | Создал файл «КП Иван» → запомнит контекст |
| **on_command** | Анализирует действия | Выполнил поиск → запомнит тему |
| **on_error** | Извлекает уроки из ошибок | Ошибка в расчётах → запомнит как избежать |
| **on_decision** | Фиксирует решения | «Решили увеличить бюджет» → запомнит |
| **on_search** | Анализирует поисковые запросы | Искал «конкуренты» → запомнит интерес |
| **on_tool_call** | Паттерны использования инструментов | Часто использует аналитику → запомнит |
| **on_session_start** | Инициализирует контекст | Начало дня → загрузит актуальные задачи |
| **on_session_end** | Финализирует наблюдения | Конец дня → сохранит итоги |
| **on_git_commit** | Привязка к коммитам | Изменение в файле → запомнит кто и зачем |
| **on_consolidation** | Консолидация по расписанию | Ночью → приберётся в памяти |

## Преимущества для бизнеса

### 1. Контекст между разговорами
Без памяти каждый разговор начинается с нуля. С AgentMemory:
- Помнит историю взаимодействия с каждым клиентом
- Знает текущие бюджеты и договорённости
- Помнит прошлые проблемы и их решения

### 2. Автоматическое обучение
Не нужно явно говорить «запомни это». Система сама понимает, что важно:
- Упомянули бюджет → запомнит
- Обсудили конкурента → запомнит
- Приняли решение → запомнит

### 3. Обнаружение паттернов
Автоматически находит скрытые закономерности:
- «Клиенты из сегмента X в среднем увеличивают бюджет через месяц»
- «Реклама в Telegram даёт в 4 раза лучшую конверсию, чем в Facebook»
- «Возражения по цене возникают у 60% новых клиентов»

### 4. Непрерывность
Если один агент начал работу — другой может продолжить с того же места. Память общая.

### 5. Поиск по изображениям
Можно находить скриншоты с результатами, креативы, графики — по текстовому описанию.

## Рекомендации

### Повседневная работа
1. **Перед встречей** — `memory_recall` по имени клиента
2. **Во время встречи** — `memory_save` для важных фактов
3. **После встречи** — `memory_lesson_save` если извлечён урок
4. **Раз в неделю** — `memory_consolidate` для систематизации

### Организация знаний
1. **Memory Slots** — для структурированных данных (клиенты, бюджеты, кампании)
2. **Facets** — для тегирования (B2B/B2C, регион, статус)
3. **Sketches** — для планирования проектов

### Командная работа
1. Каждый агент работает со своей памятью
2. Для обмена — `memory_team_share`
3. Для координации — `memory_signal_send`
